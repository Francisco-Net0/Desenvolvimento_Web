# Loja de Informática

Site para simular a compra de produtos de informática, com cálculo de subtotal, desconto por PIX, juros por cartão e valor final por parcela.

## Como rodar

1. Inicie o servidor local:

   ```bash
   php -S localhost:8000
   ```

2. Na página inicial, escolha o produto, quantidade, forma de pagamento e parcelas, e envie o formulário.
