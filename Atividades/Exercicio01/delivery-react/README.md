# 🍔 Burger - Sistema de Delivery

Projeto desenvolvido para a atividade E1 da disciplina de React JS.

## 📋 Sobre o projeto

O Burger  é um sistema web de Delivery desenvolvido em React JS. O sistema permite que o usuário navegue entre as páginas, visualize o cardápio, cadastre pedidos e visualize os pedidos cadastrados.

## 🚀 Tecnologias utilizadas

* React JS
* Vite
* React Router DOM
* JavaScript
* HTML
* CSS

## ⚙️ Funcionalidades

* Navegação entre páginas utilizando React Router DOM
* Página inicial
* Cardápio com produtos
* Formulário para cadastro de pedidos
* Gerenciamento de estados utilizando o hook `useState`
* Listagem dos pedidos cadastrados
* Contador de pedidos no menu
* Remoção de pedidos
* Interface responsiva

## 📄 Páginas

* Home
* Cardápio
* Fazer Pedido
* Pedidos

## ▶️ Como executar o projeto

Entre na pasta:

```bash
cd delivery-react
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```
